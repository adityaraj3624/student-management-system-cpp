# 🎓 Student Management System

A console-based **Student Management System** developed using **C++** to efficiently manage student records. The application provides complete CRUD functionality along with student search, topper identification, and data validation using structures and arrays.

---

## ✨ Features

- ➕ Add Student
- 📋 Display All Students
- 🔍 Search Student by Roll Number
- 👤 Search Student by Name
- ✏️ Update Student Details
- ❌ Delete Student Record
- 🏆 Display Topper
- 📊 Display Total Number of Students
- ✅ Duplicate Roll Number Validation
- ✅ CGPA Validation
- ✅ Multi-word Name Support
- ✅ Multi-word Branch Support
